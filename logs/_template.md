# 작업 제목

- 날짜:
- 프로젝트:
- 상태: 분석 중 / 구현 중 / 검증 완료
- 관련 Issue·PR·Commit:

## 1. 문제 또는 요구사항

누가 어떤 상황에서 겪는 문제인지 적습니다.

## 2. 재현과 기존 동작

입력, 실행 환경, 재현 절차와 실제 결과를 남깁니다.

## 3. 원인

문제가 생기는 코드·데이터 흐름과 확인 근거를 적습니다.

## 4. 대안과 선택

검토한 방법, 각각의 제약과 선택 이유를 적습니다.

## 5. 변경 내용

변경한 동작과 주요 파일을 설명합니다.

## 6. 검증 결과

실행한 테스트·측정 조건·결과를 기록합니다. 예상한 결과와 실제 확인한 결과를 구분합니다.

## 7. 기여와 남은 한계

본인·팀원의 작업, AI 도구의 활용 범위와 추가 검증이 필요한 부분을 적습니다.
